# Banco de questões — Simulado ELA Unit 4 (criança 7 anos)
Regra: nenhuma questão complexa ou ambígua. As de resposta aberta = fáceis e diretas.

## A) Múltipla escolha (1 resposta certa)
1. Qual grupo de animal tem **pelo (fur)**? → mammal | [fish, reptile, bird]
2. O que cobre o corpo do **reptile**? → scales (escamas) | [feathers, fur, moist skin]
3. O **reptile** nasce de quê? → egg (ovo) | [milk, plant]
4. Qual animal é **invertebrate** (sem espinha)? → jellyfish (água-viva) | [dog, snake, bird]
5. Quem come **só plantas** é...? → herbivore | [carnivore, omnivore]
6. Quem come **só carne/animais** é...? → carnivore | [herbivore, omnivore]
7. Em quantas famílias se dividem os reptiles? → 4 | [2, 3, 5]
8. Qual destes **NÃO é reptile**? → frog (rã) | [turtle, snake, crocodile]
9. O **bird** (pássaro) tem o corpo coberto de...? → feathers (penas) | [scales, fur]
10. Qual é **make-believe** (faz de conta)? → dragon | [dog, tree, school]
11. O **reptile** respira com...? → lungs (pulmões) | [gills/guelras]
12. Reptiles vivem em todo continente, MENOS...? → Antarctica | [Africa, Brazil]

## B) Verdadeiro ou Falso (True/False)
1. Frogs e toads são reptiles. → FALSE (são amphibians)
2. A pele do reptile é seca, nunca molhada. → TRUE
3. Reptiles são cold-blooded (sangue frio). → TRUE
4. A dog (cachorro) é real. → TRUE
5. A dragon (dragão) é real. → FALSE (make-believe)
6. Fish (peixes) vivem na água. → TRUE
7. O mammal mama o leite da mãe. → TRUE
8. A turtle (tartaruga) é um reptile. → TRUE
9. O insect (inseto) tem 6 patas. → TRUE
10. O bird (pássaro) tem fur (pelo). → FALSE (tem feathers/penas)

## C) Resposta aberta — autoavaliação (fáceis e diretas)
1. Diga as **4 famílias** de reptiles. → Turtles, Snakes, Lizards, Crocodilians
2. O que cobre o corpo do reptile? → scales (escamas)
3. Diga **um animal mammal**. → dog, cat, bear, ser humano... (qualquer mamífero)
4. A frog (rã) é reptile ou amphibian? → amphibian
5. O que o herbivore come? → plants (plantas)
6. Diga **uma criatura make-believe**. → dragon, super-herói, fada...
7. Onde o reptile bota os ovos? → on land (na terra)
8. Diga **um jeito de um animal se mover**. → climb, crawl, slither, walk, run, fly ou swim

## REVISÃO PÓS-PEDAGÓGICO (aplicada)
- A11: +2º distrator → `lungs | [gills, skin/pele]`
- A8: mantida, com reforço "(é amphibian)" + TTS lê o enunciado.
- +A13: Quem come plantas E animais? → omnivore | [herbivore, carnivore]
- +A14: O chameleon se esconde usando...? → camouflage | [venom, regeneration]
- +B11: O reptile é vertebrate (tem backbone). → TRUE
- C1 trocada: "Diga **UMA** família de reptile" (recall de 1, não 4).
- C6 desduplicada: "Diga uma coisa que é **REAL** (de verdade)" → dog, tree, school, sun.
- +C9 (leve, opcional): Como se diz "o maior" (big+EST)? → biggest.
- Total final: 14 MC + 11 V/F + 9 abertas = 34 itens.
